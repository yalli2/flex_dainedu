FLEX 스페인어 고득점 · UNIDAD 11

선택 영역: 말하기·쓰기

핵심 문법핵심 어휘예문연습 문제 (6세트)
학습 목표
  • FLEX 말하기 9문항의 유형별 답변 틀을 익힌다
  • FLEX 쓰기 10문항의 유형별 작성법을 익힌다
  • 번역·요약·데이터 분석 답안을 작성할 수 있다

핵심 문법

말하기 답변 틀

녹음식으로 진행되며 준비 시간 후 답변합니다.

유형답변 틀
자기소개이름 → 직업/전공 → 사는 곳 → 취미 → 스페인어를 배우는 이유
낭독강세·연음에 주의해 천천히 또박또박
사진·삽화 묘사장소 → 인물 → 행동(están + 현재분사) → 추측
역할 설정인사 → 목적 → 요청/질문 2~3개 → 감사
데이터 분석자료 소개 → 최고·최저 → 비교 → 해석
의견 진술입장 → 이유 2개 + 예시 → 결론

쓰기 유형

단문 번역(한→서 5문장), 내용 요약(긴 글을 3~4문장으로), 담화 구성(문장 순서 배열·연결), 데이터 분석(표·그래프 해설), 서신·메모(업무 이메일), 주제별 작문(의견문). 번역은 직역보다 자연스러운 스페인어 구문을 우선하세요.

예문

  • Según el gráfico, el número de turistas extranjeros se ha duplicado en los últimos diez años.그래프에 따르면 외국인 관광객 수는 지난 10년간 두 배가 되었다.

연습 문제

세트마다 채점하기를 누르거나, 아래의 전체 채점으로 한 번에 점수를 확인하세요. 빈칸은 강세 부호(á, é, ñ…)까지 맞아야 정답이며, 강세만 틀리면 0.5점입니다.

주의
말하기·쓰기는 민간자격이므로 제출처가 듣기·읽기 성적만 요구하는지 먼저 확인하세요. 공공기관 가산점은 대부분 듣기·읽기 성적 기준입니다.
