문법 핵심 3: 대명사·전치사·관계사

핵심 문법핵심 어휘예문연습 문제 (4세트)
학습 목표
  • 목적격·재귀 대명사의 형태와 위치를 정리한다
  • 동사와 짝을 이루는 전치사를 암기한다
  • 관계사 que, quien, cuyo, lo que, el cual을 구분한다

핵심 문법

대명사 위치와 결합

활용 동사 앞: Lo veo. / 동사원형·현재분사·긍정 명령 뒤 붙여 쓰기: Quiero verlo. Estoy leyéndolo. Dímelo. / 간접 le(s) + 직접 lo/la → se lo/se la: Se lo di a María.

전치사가 따라오는 동사

FLEX 문법·오문 정정의 단골입니다.

전치사동사
aaprender a, empezar a, ayudar a, invitar a, acostumbrarse a, negarse a, atreverse a
deacordarse de, olvidarse de, depender de, tratar de, enamorarse de, darse cuenta de, quejarse de

POR vs PARA

para: 목적, 목적지, 기한, 대상(Estudio para aprobar / Salgo para Lima / Es para mañana / Es para ti). por: 원인, 경로, 대가, 수단, 기간, 수동태 행위자(Lo hice por ti / Paseo por el parque / Lo compré por 10 € / por teléfono / por la mañana / escrito por Cervantes).

관계사

cuyo/a/os/as는 뒤 명사에 성수 일치: El autor cuya novela leí. / 전치사 + el que/el cual: La empresa para la que trabajo. / lo que: 앞 문장 전체 또는 ‘~하는 것’.

예문

  • No me acuerdo de su nombre.그의 이름이 기억나지 않는다.
  • El proyecto consiste en tres fases.프로젝트는 3단계로 이루어진다.
  • Es la empresa para la que trabaja mi hermano.내 동생이 일하는 회사이다.

암기 TIP
전치사 동사는 ‘동사 + 전치사 + 예문’ 세트로 카드를 만들어 하루 20개씩 반복하세요. 예: soñar con → Sueño con ser médico.
